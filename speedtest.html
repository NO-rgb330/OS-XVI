Upload speed test

Measures how fast this browser can store a big file, written normally versus split into parts written at the same time. Nothing leaves your computer. All test data is deleted from browser storage after each run.

Tip: close other heavy tabs and apps first. If the file is smaller than the chosen amount, the whole file is used. 4 GB or more gives the fairest result because it is bigger than what the system can hold in its write cache.
